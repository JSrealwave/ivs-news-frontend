# IVS News brand marks

Site chrome uses the **white raven on `#09090b`** as favicon (`app/icon.png`)
and the **white raven + white wordmark** in the header/footer.

Wordmarks are transparent PNGs split from the Grok Imagine sheet
(`source/IVS_logo_Blue+White.jpg`). The raven mark is derived from
`raven-wht-dark-bg.jpg`.

| Use | File | Size |
|---|---|---|
| Master | `light/ivs-news-master.png` · `dark/ivs-news-master.png` | 1000×~195 |
| Header | `light/ivs-news-header.png` · `dark/ivs-news-header.png` | 320×~62 |
| Beehiiv / email | `light/ivs-news-email.png` · `dark/ivs-news-email.png` | 480×~94 |
| Favicon | `light/favicon-{32,64,512}.png` · `dark/favicon-{32,64,512}.png` | square |

- **Light** = navy `#092143` on transparent. Use on white / light backgrounds (email).
- **Dark** = white on transparent. Use on the dark site header.
- **Favicon light** = navy I on white square. **Favicon dark** = white I on navy square.

Web copies live in `public/logo/` (`/logo/...` on the site). Favicon is not wired into `app/` yet.
